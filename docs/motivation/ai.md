title: AI Statement
---

For the most part, Butterfloat is a human-created endeavour. It is
intentionally idiosyncratic, weird, at times silly, and _creative_ as a
project. Butterfloat is useful to LLM projects in many ways (it allows
reusing a lot of React and RxJS training, and has useful types that
guide toward best practices), but it provides that by being human-curated.

I have put in a lot of very personal hard work into this project,
including laboring over getting the API "just right" for my own sense of
human memorability and ability to work "from scratch" as easily as
"agentic" or whatever the next lifestyle fad for development may be. I
wrote all the documentation by hand to better focus on the rhythm and
pacing of it, and its ability to teach people as much or more than
machines.

Some LLM usage has been warranted in the life of this project. It has
been kept mostly to:

- Some Copilot code reviews
- Copilot Autocomplete and Next Edit Suggestions (centaur mode)

Butterfloat has been a labor of love, and I have not been convinced that
it would be half as innovative or interesting if it were made by a
reverse centaur.
